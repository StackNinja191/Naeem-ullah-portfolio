## 🛠️ CUSTOMIZATION

### Change Colors
Edit `css/style.css`:
```css
:root {
    --accent-blue: #0ea5e9;    /* Change this */
    --accent-purple: #8b5cf6;  /* Change this */
    --accent-cyan: #06b6d4;    /* Change this */
}
```

### Change Fonts
Edit the Google Fonts link in `index.html`:
```html
<link href="https://fonts.googleapis.com/css2?family=..." />
```

### Add More Projects
Copy a project card in `index.html` and modify:
```html
<div class="project-card glass-effect rounded-xl overflow-hidden tilt-card" data-category="web">
    <!-- Update icon, title, description, links -->
</div>
```
